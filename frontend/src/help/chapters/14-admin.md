# 管理者向け

管理者（管理者のグループに所属している人）は、すべてのワークスペース・ページを閲覧・編集できます。管理者だけが使える機能はサイドメニュー下のリンクと、ワークスペースの「⋯ 操作」にあります。

## 監査ログ

サイドメニュー下の「監査ログ」。ページの作成・削除・共有設定の変更・公開・権限の申請の許可・自動化ルールや Webhook の設定・バックアップなど、重要な操作を、誰が・いつ・何をしたかで記録しています。操作の種類で絞り込めます。

## 公開中のページ

サイドメニュー下の「公開中のページ」。ゲスト向けに公開されているページの一覧（公開期間・パスワードの有無・公開版の固定・検索エンジン）を確認し、公開を止められます。

## 定期バックアップ

ワークスペースの「⋯ 操作」→「💾 定期バックアップ」。

1. 「毎日バックアップする」にチェックし、時刻と残す数（世代）を決めて「保存」。
2. 毎日その時刻ごろに、ワークスペースのすべてのページ（権限を絞ったページも）を ZIP にして保存します。古いものから消えます。
3. 「今すぐバックアップ」で、その場で作ることもできます。一覧から「ダウンロード」できます。

**ZIP の中身**: 書き出しの ZIP と同じ形（フォルダ構成の Markdown・添付ファイル・ホワイトボード）で、そのまま [取り込み](/help/io#取り込む) で戻せます。ページの親子・本文の元データ・ラベル・データベースの定義と値は `skiwi-backup.json` に入っています。

> バックアップにはすべてのページが入るため、管理者だけが扱えます。ダウンロードしたファイルの扱いに注意してください。

## ユーザーとグループ

ユーザーとグループは、ログインに使っている認証基盤（IdP）から取り込まれます。所属するグループを変えたい場合は、認証基盤の管理者に依頼してください。

## draw.io のエディタ

[draw.io の図](/help/blocks#drawio-の図) の編集には、既定で diagrams.net のエディタ（`https://embed.diagrams.net`）を使います。エディタはブラウザの中で動き、図のデータは skiwi のサーバーにだけ保存されます（diagrams.net には送りません）。

- 社外のサイトにつなげない環境や、社内のものを使いたいときは、draw.io（`jgraph/drawio` の Docker イメージなど）を社内に置き、サーバーの環境変数 `DRAWIO_URL` にその URL を設定します。
- `DRAWIO_URL` を空にすると、図を編集できなくなります（表示はできます）。
