# はじめに

skiwi は、チームの手順書・議事録・仕様・ノウハウなどを **ページ** にまとめ、何人でも **同時に編集** し、必要な人と **共有** するための道具です。社外の人にページを **公開** することもできます。

## できること

| やりたいこと | 使う機能 | 説明 |
| --- | --- | --- |
| 情報をまとめる | ページ・子ページ | [ページとワークスペース](/help/pages) |
| 書く・図を描く | エディタ・ホワイトボード | [ページを書く](/help/editing)、[いろいろなブロック](/help/blocks) |
| 一緒に作業する | 同時編集・コメント・メンション | [一緒に作業する](/help/collab) |
| 探す | 検索・ラベル・お気に入り | [探す](/help/find) |
| 見せる範囲を決める | 共有・保護・期限付きの権限 | [共有と権限](/help/sharing) |
| 一覧で管理する | データベース（表・ボード・カレンダー） | [データベース](/help/database) |
| 社外に見せる | ゲスト向けの公開 | [ゲスト向けの公開](/help/public) |
| 自動で知らせる | 自動化ルール・Slack・Teams | [自動化と外部連携](/help/automation) |

## 画面の見方

画面は、いちばん上の **ヘッダ**、その下の **左のサイドメニュー** と **右のページ** に分かれます。

### ヘッダ（上）

- **左**: ☰（サイドメニューを閉じているとき、開くボタン）と skiwi のロゴ。ロゴを押すと最初の画面に戻ります。
- **右**: 自分のアイコン。押すとメニューが開きます: 🖼 アイコンを変更、表示の明暗の切り替え、📖 使い方、外部サービスとの連携（管理者が設定したときだけ）、APIトークン・API の説明書、管理者向けの画面（管理者だけ）、ログアウト。

### 自分のアイコン

画面右上の自分のアイコン →「🖼 アイコンを変更」→「画像を選ぶ…」で、画像を選んで「保存」します。

- 画像は真ん中を正方形に切り抜き、小さくしてから保存します。
- アイコンはヘッダのほか、同じページを開いている人の表示や、コメントの名前の横に出ます。ほかの人にも見えます。
- 設定していないときは、名前の1文字目を色付きの丸で出します。「アイコンを外す」で、いつでもこの表示に戻せます。

### サイドメニュー（左）

- **ワークスペースの選択欄**（いちばん上）: ワークスペースは、部署やプロジェクトごとのページのまとまりです。切り替え・新規作成はここから。
- **☆ お気に入り / ⋯ 操作 / 🔔 通知 / ⌘ クイック切り替え**: ワークスペースのお気に入り登録、ワークスペースの操作（共有・点検・ゴミ箱など）、通知、どこからでも移動できる小窓。
- **検索欄**: ページとワークスペースを探します。右の「⚙」で絞り込み。
- **📄 ページ / 🕘 最近 / 🏷 ラベル / ✅ ToDo**: 表示の切り替え。ふだんは「ページ」のツリー（階層）を使います。
- **＋ 新規ページ**（いちばん下）: ワークスペースの直下にページを作ります。
- サイドメニューは「«」または <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>\</kbd> で閉じられます。閉じたあとはヘッダの「☰」で開きます。

### ページ（右）

- **右上のボタン**: 🔔 ウォッチ、☆ お気に入り、💬 コメント、🕘 履歴、⤓ 書き出し、🎨 スタイル、🔒 保護、👥 共有、✏️ 編集。画面が狭いとアイコンだけになります。
- **タイトルの下**: 📌 状態（下書き・レビュー中など）、👤 所有者、🏷 ラベル。
- **本文**: ふだんは読むための「表示モード」です。「✏️ 編集」（または <kbd>E</kbd> キー）で編集モードになります。

## 最初の一歩

1. サイドメニュー下の **「＋ 新規ページ」** を押します。
2. タイトルを入力し、本文を書きます。行の先頭で <kbd>/</kbd> を押すと、見出し・表・ToDo などを挿入できます。
3. 書いた内容は **自動で保存** されます。保存ボタンはありません。書き終えたら右上の「完了」で表示モードに戻ります。
4. ほかの人に見てもらうには、右上の **「👥 共有」** で相手を追加します（ワークスペースのメンバーなら最初から見られる場合もあります）。

> 💡 困ったときは、画面で <kbd>?</kbd> キーを押すとショートカットの一覧、<kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>K</kbd> で操作や移動先を名前で探せます。このマニュアルは各画面の「？ 使い方」や画面右上の自分のアイコンのメニューの「📖 使い方」から開けます。
