# ページを書く

## 表示モードと編集モード

ページはふだん **表示モード**（読むための状態）で開きます。誤って書き換えないためで、リンクや目次もそのままクリックできます。

- **編集を始める**: 右上の「✏️ 編集」、または <kbd>E</kbd> キー。
- **編集を終える**: 右上の「完了」、またはエディタの外で <kbd>Esc</kbd>。
- 新しく作ったページ・タイトルが空のページは、最初から編集モードで開きます。
- 閲覧権限だけのページ、[保護](/help/sharing#ページの保護) されたページでは「編集」は出ません。

## 自動保存

入力した内容は自動で保存され、同じページを開いているほかの人の画面にもすぐ反映されます。ページ下部に「● 同期済み」と出ていれば保存済みです。
通信が切れても入力は続けられ、つながり直したときにまとめて保存されます。

## 文字の装飾

文字を選ぶと、上に小さなメニューが出ます。

| ボタン | 意味 | キー |
| --- | --- | --- |
| **B** | 太字 | <kbd>⌘</kbd>/<kbd>Ctrl</kbd>+<kbd>B</kbd> |
| *I* | 斜体 | <kbd>⌘</kbd>/<kbd>Ctrl</kbd>+<kbd>I</kbd> |
| U | 下線 | <kbd>⌘</kbd>/<kbd>Ctrl</kbd>+<kbd>U</kbd> |
| S | 取り消し線 | <kbd>⌘</kbd>/<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> |
| &lt;/&gt; | コード | <kbd>⌘</kbd>/<kbd>Ctrl</kbd>+<kbd>E</kbd> |
| 🖍 | ハイライト（マーカー） | <kbd>⌘</kbd>/<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> |
| 🔗 | リンク | |
| A | 文字の色・背景の色（10色。「色をすべて外す」で戻す） | |
| 💬 | 選んだ部分にコメント（表示モードでも使えます） | |

色はダークモードでも読みやすい色に自動で切り替わります。

## ブロックのつまみ

編集モードで段落・見出し・リスト・画像などにマウスを乗せると、左に **⋮⋮** のつまみが出ます。

- **ドラッグ**: ブロックごと上下に移動します。
- **クリック**: ブロックのメニューを開きます。
  - **🔁 変換**: テキスト・見出し1〜3・箇条書き・番号付き・ToDo・引用・コード・開閉ブロックに変えます。
  - **🎨 色**: ブロック全体の文字の色・背景の色。
  - **⧉ 複製**: すぐ下に同じブロックを作ります。
  - **🔗 ブロックへのリンクをコピー**: このブロックを直接開く URL（`…#block-xxxx`）をコピーします。ほかのページに貼り付けると「ページ名 › ブロック」のリンクになり、開くとそのブロックまでスクロールして一瞬光ります。
  - **↪ 別のページへ移動…**: 選んだページの末尾へ移します（移動先を編集できる権限が必要です。ホワイトボードは移せません）。
  - **🗑 削除**

## 「/」でブロックを挿入する

行の先頭（または空白のあと）で <kbd>/</kbd> を押すと、挿入できるものの一覧が出ます。続けて文字を入れると絞り込めます（例: `/ひょう` → 表、`/todo` → ToDoリスト）。
矢印キーで選んで <kbd>Enter</kbd>。「すべてのブロックを表示…」で分類ごとの一覧から選べます。

主なもの: 見出し1〜3・開閉見出し・箇条書き・番号付きリスト・ToDoリスト・表・引用・コード・画像・ファイル・ホワイトボード・段組み・開閉ブロック・パネル（注意・ヒントなど）・目次・ページへのリンク・同期ブロック・数式・Mermaid図・埋め込み・ブックマーク・データベース（ページ内）・区切り線。
それぞれの使い方は [いろいろなブロック](/help/blocks) にあります。

## 絵文字（「:」）

<kbd>:</kbd> に続けて名前を入れると、絵文字の候補が出ます（例: `:smile` → 😀、`:笑` → 😄。英語・日本語・ひらがなで探せます）。矢印キーで選んで <kbd>Enter</kbd>。

## 書きながら変換される記法

行の先頭で次のように入力すると、その場で変換されます（Markdown と同じ書き方）。

| 入力 | 結果 |
| --- | --- |
| `#` + スペース（`##`、`###`） | 見出し1（2、3） |
| `-` + スペース | 箇条書き |
| `1.` + スペース | 番号付きリスト |
| `[ ]` + スペース | ToDo |
| `>` + スペース | 引用 |
| ` ``` ` | コードブロック |
| `---` | 区切り線 |
| `**文字**` / `*文字*` / `` `文字` `` | 太字 / 斜体 / コード |

## 画像・ファイル

- **貼り付け**: スクリーンショットや画像をコピーして、本文に <kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>V</kbd>。カーソルの位置に入ります。名前のない画像には日時から名前（例: `貼り付け-20261107-103000.png`）を付けます。
- **ドラッグ＆ドロップ**: パソコンの画像・ファイルを本文に落とします。落とせる場所は点線で囲まれ、落とした位置に入ります。複数のファイルをまとめて落とすと、選んだ順に並びます。
- **`/画像`・`/ファイル`**: ファイルを選んでアップロードします。
- 画像は画像として、それ以外（PDF・Excel など）はファイル名のカードとして入ります。カードをクリックするとダウンロードできます。
- **画像の大きさ・寄せ・キャプション**: 画像を選ぶと四隅のつまみで大きさを変えられ、上に「左・中央・右」の寄せが出ます。画像の下の「キャプションを追加」に説明文を書けます。
- アップロード中は、ページ下部に「アップロード中…（◯件）」と出ます。
- 編集モードのときだけ追加できます。表示モードの本文やエディタの外に落としても、何も起きません。
- 添付できる大きさには上限があります（既定 100MB）。

## リンク

- **ウェブのリンク**: 文字を選んで 🔗、または URL をそのまま貼り付け。
- **URL だけを貼り付けたとき**: 小さなメニューで形を選べます。
  - **🔗 リンクのまま**（何もしなければこれ）
  - **🔖 カード**: ページのタイトル・説明・画像を読み込んで、ブックマークのカードにします。
  - **▶ 埋め込み**: YouTube・Vimeo・Figma・Google ドキュメント／スプレッドシート／スライド／ドライブ・Loom・Miro・CodePen・Spotify などは、本文の中にそのまま表示します（対応するサービスのときだけ出ます）。
- **ページ内の見出し・ブロックへのリンク**: ブロックのつまみの「ブロックへのリンクをコピー」で（[ブロックのつまみ](#ブロックのつまみ)）。
- **skiwi のページへのリンク**: `/ページへのリンク` で検索して選ぶか、ページの URL を貼り付けます。リンクにはページ名が自動で表示され、名前を変えても追従します。
  閲覧できないページへのリンクは「🔒 アクセスできないページ」と表示され、開くと [閲覧権限を申請](/help/sharing#閲覧権限の申請) できます。
- ページの下部「↩ このページへのリンク」に、このページにリンクしているページが一覧されます。

## タイトル・アイコン・ラベル

- タイトルは本文の上の大きな欄です。
- 編集モードでは「＋ アイコンを追加」から絵文字のアイコンを付けられます（サイドメニューにも表示）。
- 「＋ ラベル」でラベルを付けると、同じラベルのページを一覧したり、検索で絞り込んだりできます（[探す](/help/find#ラベル)）。

## 全幅表示

右上の「↔ 全幅」で、本文を画面の横幅いっぱいに広げます（大きな表やデータベースのページ向け）。設定はページごとで、そのページを見るすべての人に効きます。「↔ 標準の幅」で戻します。

## パンくずリスト

ページのタイトルの上に、親ページのたどり（例: `ワークスペース › 設計 › API`）が出ます。クリックでそのページへ移動します。

## ページの見た目（スタイル）

右上の「🎨 スタイル」で、ページに CSS を設定できます（文字の色・余白・表の装飾など）。子ページにも効かせるか選べます。ワークスペース全体のスタイルは「⋯ 操作」→「🎨 スタイル」。
画面を壊すような記述は自動で取り除かれ、効くのは本文の表示エリアの中だけです。
