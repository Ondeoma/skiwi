# 通知・ウォッチ・ToDo

## 通知

サイドメニューの「🔔 通知」に届きます。数字は未読の数です。通知をクリックするとそのページ（コメントならそのスレッド）を開きます。
同じ内容はメールでも届きます（メールの設定がある場合）。

| 通知 | 届くとき |
| --- | --- |
| 更新 | ウォッチしているページが、ほかの人に更新されたとき（同じページの未読は1件にまとまります） |
| コメント | ウォッチしているページ・参加しているスレッドにコメントがあったとき |
| メンション | コメント・本文で `@` で呼ばれたとき |
| 共有 | ページ・ワークスペースが自分と共有されたとき |
| ToDo の期限 | 自分が担当の ToDo の期限が近づいた・過ぎたとき |
| 権限の申請・許可 | 権限の申請を受けた・許可された・却下されたとき |
| 自動化 | ワークスペースの [自動化ルール](/help/automation#自動化ルール) から |

見られなくなったページの通知は表示されません。

## ウォッチ

ページ右上の「🔔」で、そのページの通知の受け取り方を選びます。自分で作ったページは最初からウォッチしています。

- **本文の更新**: ほかの人が本文を変えたとき。編集が5分止まったら、最長でも30分ごとに1通にまとめて送ります。
- **コメント**: コメントがあったとき。
- **子ページも含める**: その下のすべてのページの通知も受け取ります。子ページに個別の設定をすると、そちらが優先されます。
- 「ウォッチをやめる」で止めます。

ボタンの表示: 「ウォッチ中」（両方）、「コメントのみ」、「更新のみ」、「ウォッチ中（親）」（親ページの「子ページも含める」で届いている）。

## ToDo

本文の ToDo リストに担当者（`@名前`）と期限（`/期限`）を付けると、担当者のサイドメニュー「✅ ToDo」に並びます（すべてのワークスペース）。

- 未完了のものを期限の近い順に表示します。「完了も表示」で済んだものも見られます。
- クリックでそのページを開きます。チェックはページで付けます。
- 期限が今日・明日・過ぎた ToDo は、担当者に通知します（同じ ToDo には1回だけ）。
