# データベース

データベースにすると、ページの **子ページを項目** として、表・ボード（カンバン）・リスト・ギャラリー・カレンダー・タイムラインで一覧・管理できます。案件管理、問い合わせ管理、タスク管理などに向いています。項目は普通のページなので、本文も書けます。

## データベースを作る

1. ページを編集モードにします。
2. タイトルの下の「📊 データベースにする」を押します。
3. 「状態（未着手・進行中・完了）」「担当者」「期限」の列と、表・ボード・カレンダーのビューが用意されます。あとから自由に変えられます。

サイドメニューでは 📊 のアイコンで表示されます。

## 項目を追加する

- **表**: いちばん下の欄に名前を入れて <kbd>Enter</kbd>。
- **ボード**: 列の下の「＋ 追加」（その列の値が入ります）。
- **カレンダー**: 日にちの「＋」（その日付が入ります）。
- サイドメニューで、データベースのページの下に子ページを作っても項目になります。
- たくさんの項目は [CSV から取り込み](#csv) ます。

項目名をクリックすると、その項目のページを開きます。項目のページの上部に値が表示され、そこでも変えられます。

## 値を入れる

表のセルをクリックして入力します（テキスト・数値は <kbd>Enter</kbd> で確定、<kbd>Esc</kbd> で取り消し）。

| 列の種類 | 入れ方 |
| --- | --- |
| テキスト・数値・URL | クリックして入力 |
| 選択・複数選択 | 選択肢から選ぶ（色付きのラベル） |
| 日付 | カレンダーから選ぶ |
| ユーザー | 「＋」で名前・メールを検索して追加 |
| チェック | チェックボックス |
| 関連 | 「＋」で関連先のデータベースの項目を選ぶ |
| 集計 | 自動で計算（入力しない） |
| 数式 | ほかの列から自動で計算（[数式](#数式)） |
| 作成日時・更新日時・作成者・更新者 | 自動で入る（入力しない） |
| ID | 項目ごとの通し番号（例: `TASK-12`）。自動で入り、変わりません。列のメニューで接頭辞（`TASK` など）を付けられます |

自動で入る列は、項目のページの上部には表示されません（ページの作成者・更新日時はページの下部で確かめられます）。
## 列を変える

表の見出し（列名）をクリックすると、列のメニューが開きます。

- 名前の変更・種類の変更・左右への移動・このビューで隠す・削除
- 選択肢の追加・名前の変更（クリック）・色・削除
- 列の追加は、見出しの右端の「＋」

## ビュー

上のタブでビューを切り替えます。「＋」でビューを追加でき、同じ種類のビューを条件違いで複数作れます（例:「自分の担当」「今月」）。
タブのダブルクリック、または「⋯」で名前の変更・削除。

- **表**: 行と列で一覧し、その場で編集します。
- **ボード**: 「選択」の列（例: 状態）ごとに縦に並べます。カードをドラッグで別の列に移すと、値が変わります。
- **リスト**: 項目名と、いくつかの値を1行ずつ並べた、すっきりした一覧です。
- **ギャラリー**: 項目をカードで並べます。カードの絵（カバー）は「本文の最初の画像」か「URL の列」から選べ、本文の書き出しも表示します。
- **カレンダー**: 「日付」の列で月ごとに並べます。項目をドラッグで別の日に移すと、日付が変わります。日付のない項目は下にまとまります。
- **タイムライン**: 「開始」と「終了」の日付の列で、項目を横棒（ガントチャート）で並べます。棒をドラッグすると日程ごと移動し、両端をドラッグすると開始・終了を変えられます。終了の列を「なし」にすると1日だけの棒になります。

## 計算（表の下の集計）

表のいちばん下の行で、列ごとに **件数・値のある件数・空の件数・合計・平均・最小・最大・チェックあり・チェックなし** を表示できます（列の種類で選べるものが変わります）。絞り込み後の項目が対象で、設定はビューごとに保存されます。

## グループ化

「⚙ 絞り込み・並べ替え」の「グループ」で、表・リストを **選択・チェック・ユーザー** の列の値ごとに区切ります。区切りの見出しをクリックすると畳めます。

## サブ項目

項目の下に、さらに項目（サブ項目）を作れます。大きなタスクを小さく分けるときに使います。

- 表の項目名にマウスを乗せて「＋」→ サブ項目の名前を入力。
- 「⚙ 絞り込み・並べ替え」で「サブ項目を親の下に表示」にすると、親の左の ▸ で開閉できます。オフにすると、すべての項目が平らに並びます。
- サブ項目は親のページの子ページです。列・値は親と同じデータベースのものを使います。

## 数式

列の「＋」→「数式」で、ほかの列から値を計算します。`prop("列名")` で列の値を使います。

```
prop("単価") * prop("数量")
if(prop("完了"), "✅", "⏳")
dateBetween(prop("期限"), today(), "days")
concat(prop("名前"), "（", prop("担当"), "）")
```

使える演算子: `+ - * / %`、比較 `== != > >= < <=`、`and` `or` `not`。
使える関数: `if`・`empty`・`concat`・`join`・`length`・`contains`・`replace`・`upper`・`lower`・`toNumber`・`round`・`floor`・`ceil`・`abs`・`min`・`max`・`sum`・`now`・`today`・`year`・`month`・`day`・`weekday`・`dateBetween`・`dateAdd`・`dateSubtract`・`formatDate`（`"YYYY/MM/DD HH:mm"`）。
式に誤りがあるときは、セルに「⚠」と出ます。列のメニューの「数式を編集」で直します。

## フォーム

フォームを作ると、skiwi にログインしていない人からも回答を集められます。回答はデータベースの **項目** になります（問い合わせ・申し込み・アンケートなど）。

1. ビューの「⋯」→「📝 フォーム（回答が項目になる）」→「＋ フォームを作る」。
2. タイトル・説明と、質問にする列（テキスト・数値・選択・複数選択・日付・チェック・URL と項目名）を選びます。列ごとに表示名・説明・「必須」を設定できます。
3. 一覧に出る回答用の URL（`/f/…`）を「コピー」して共有します。回答の件数と最後の回答日時も確かめられます。

- **回答にはログインが必要**: オンにすると、ログインした人だけが回答でき、選んだユーザーの列に回答した人が入ります。
- **回答を受け付ける**: オフにすると「停止中」になり、その URL では回答できなくなります（削除しても同じです）。
- 回答の項目は、フォームを作った人が作成したものとして記録されます。同じフォームへの送信が短い時間に集中すると、しばらく受け付けません。

## 絞り込み・並べ替え・検索

「⚙ 絞り込み・並べ替え」で、ビューごとに条件を保存します。

- **条件**: 「名前 に含む」「状態 が 完了 でない」「期限 より前」「担当者 に含む 自分」「金額 より大きい」「空 / 空でない」など。複数の条件はすべてを満たすものを表示します。
- **並べ替え**: 名前・更新日時・各列の昇順／降順。
- **ボードの列に分ける項目**・**カレンダーの日付の項目** もここで選びます。
- 上の「🔍 検索」は、名前と値をまとめて探します（一時的）。

> 閲覧権限だけの人がビューを変えても、その人の画面だけに反映されます。

## 関連と集計

### 関連（別のデータベースの項目を指す）

例: 「案件」データベースから「顧客」データベースの項目を指す。

1. 列の「＋」→「関連（別のデータベース）」→ 関連先のデータベースを選ぶ。
2. セルの「＋」で関連先の項目を選びます（複数可）。クリックでその項目を開けます。

### 集計（関連先の値をまとめる）

例: 「顧客」データベースで、関連する案件の金額の合計を表示する。

1. 先に「関連」の列を作ります。
2. 列の「＋」→「集計（関連先の値）」→ どの関連か → 集計のしかた → 関連先のどの列か、を選ぶ。

集計のしかた: 件数・値のある件数・合計・平均・最小・最大・チェック済みの割合。値は自動で計算されます。

## CSV

ビューの「⋯」から使います。

- **CSVで書き出し**: 表示中の項目と列を CSV にします（Excel で開けます。数式・自動で入る列は計算した値を書き出します）。
- **CSVから取り込み**: 1行目を列名にした CSV を選びます。
  - 「名前」（または「タイトル」）の列が項目名になります。なければ1列目。
  - ほかの列は、同じ名前の列に値を入れます。ない列はテキストの列として追加します。
  - 選択肢は名前で対応し、足りない選択肢は追加します。日付は `2026/1/5`・`2026-01-05`・`2026年1月5日` を読めます。チェックは `TRUE`・`1`・`はい`・`✓` など。
  - Excel で保存した CSV（Shift_JIS）も読めます。一度に2000行まで。

## データベースをやめる

「⚙ 絞り込み・並べ替え」の下の「データベースをやめる…」で、普通のページに戻します。子ページと入力した値は残り、もう一度データベースにすると表示されます。
データベースのページを [複製](/help/pages#ページの複製) すると、列・ビュー・値も一緒に複製されます。
