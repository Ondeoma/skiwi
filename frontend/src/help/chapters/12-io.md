# 取り込み・書き出し・PDF

## 取り込む

ほかのツールで書いた文書を、skiwi のページにします。

- **ワークスペースの直下に**: 「⋯ 操作」→「⤒ 取り込む」。
- **あるページの子ページとして**: サイドメニューのページの「⋯」→「⤒ 子ページとして取り込む」。

取り込めるもの:

- **Markdown**（`.md`）・**HTML**。複数のファイルをまとめて選べます。
- **Word**（`.docx`）: 見出し・リスト・表・画像を変換します。Google ドキュメントは「ファイル → ダウンロード → Microsoft Word（.docx）」で保存して取り込みます。
- **CSV**（`.csv`）: データベースとして取り込みます（1行目が列名。列の種類は値から推測します）。
- **ZIP**: フォルダの構成がページの親子になります（`A.md` と `A/` フォルダは同じページ、`A/index.md`・`README.md` はフォルダのページの本文）。中の画像・添付ファイルはアップロードし、ファイル同士のリンクはページへのリンクに、`.excalidraw` はホワイトボードに戻します。

### Notion から

Notion で「エクスポート」→ 形式「Markdown と CSV」（「サブページを含める」をオン）で ZIP を作り、そのまま取り込みます。

- ページ名の後ろに付く ID（`設計 1a2b3c…`）は取り除きます。ページ同士のリンクは skiwi のページへのリンクになります。
- Notion のデータベース（CSV）は、skiwi のデータベースになります。CSV にない項目のページ（本文）もその項目に入ります。
- ZIP の中に ZIP が入っている（大きなワークスペースの書き出し）場合も、そのまま読めます。

### Confluence から

スペースの「エクスポート」→「HTML」で ZIP を作り、そのまま取り込みます。`index.html` の目次からページの親子を組み立て、本文（`main-content`）だけを取り出します（ページ名の前の「スペース名 :」は外します）。draw.io の図（「図名.png」と図のデータのファイル）は、draw.io の図のブロックにします。添付画像もアップロードします。

### 共通

先頭の見出し1がページ名になります。`.drawio.png`（図入りの PNG）・`.drawio` のファイルは、draw.io の図のブロックになります。表・ToDo（`- [ ]`）・コード・Mermaid（` ```mermaid `）・数式（`$$…$$`）も変換します。一度に500ページ・合計100MBまで。

> skiwi で書き出した ZIP や、[定期バックアップ](/help/admin#定期バックアップ) の ZIP も、そのまま取り込めます。

## 書き出す

ページ右上の「⤓ 書き出し」から。

- **Markdown**: このページを `.md` で保存します。
- **ZIP**: 子ページ・添付ファイルも含めて、フォルダ構成の Markdown にします（添付は `attachments/`、ホワイトボードは `.excalidraw`、ページ間のリンクは相対パス）。
- **印刷 / PDF**: このページをブラウザの印刷画面で開きます。「送信先」で「PDF に保存」を選ぶと PDF になります。
- **PDF（子ページも含めて）**: 新しいタブに、表紙・章番号付きの目次・ページごとの改ページを付けて1冊にまとめ、印刷画面を開きます。上部で「子ページも含める」「目次を付ける」を切り替えられます。閲覧できるページだけが入ります。
- **複製**: [ページの複製](/help/pages#ページの複製)。

公開中のページは、ゲストに見えている内容のまま PDF にすることもできます（[ゲスト向けの公開](/help/public#pdf-にする)）。
