# ゲスト向けの公開

社外の人など、ログインしない人（ゲスト）にページを読んでもらう機能です。ゲストは閲覧だけで、編集・コメントはできません。

## 公開する

1. ページ右上の「👥 共有」を開き、「🌐 ゲストに公開」の「リンクを知っている人は、ログインしなくても閲覧できる」にチェック。
2. 表示された URL をコピーして相手に伝えます。
3. 「子ページも公開する」にすると、子ページもまとめて公開します（権限を絞った子ページは除きます）。

公開中のページはサイドメニューに 🌐 が付きます。チェックを外すと公開をやめ、そのリンクは使えなくなります（もう一度公開すると別のリンクになります）。

## 公開する内容（公開版の固定）

- **編集中の内容をそのまま公開する**（既定）: 本文を直すと、ゲストにもすぐ反映されます。
- **「公開」を押した時点の内容を公開する**: ゲストには公開した時点の内容を見せ、編集中の変更は見せません。直し終わったら「現在の内容を公開」で反映します。反映していない変更があると「⚠」で知らせます。

### 変更点のメモと公開の履歴

公開版を固定しているときは、「現在の内容を公開」の前に **変更点のメモ** を書けます。

- 「公開の履歴」に、公開日時・公開した人・メモが残ります。「前回との差分」で、何が変わったかをページごとに確認できます。メモはあとから編集できます。
- 「ゲストの画面に『更新履歴』を出す」にすると、ゲスト画面に「🕘 更新履歴」が出て、公開日時とメモを読めます。

## 公開期間

- **開始**: 指定した日時までゲストは見られません（「◯から公開されます」と表示）。予約公開に使います。
- **終了**: 指定した日時を過ぎると見られなくなります（「公開期間が終わりました」と表示）。

## パスワード

公開リンクにパスワードを付けられます。ゲストはパスワードを入れると閲覧できます（10分間に10回まで試せます）。

## わかりやすい URL と検索エンジン

- **URL名**: `/s/manual` のような名前を付けられます（英小文字・数字・ハイフン）。子ページは、そのページの共有画面の「このページのURL名」で `/s/manual/install` のようにできます。
- **検索エンジンに載せる**: 既定では載せません。チェックすると、検索エンジンに載せてよいと伝えます（載るかどうか・いつ載るかは検索エンジンしだいです。パスワード付きは載せません）。
- **共有したときの説明文**: チャットや SNS に URL を貼ったときに出る説明。空欄なら本文の冒頭を使います。

## ゲストの画面の見た目

- **サイドメニュー（ページ一覧）**: 自動（2ページ以上なら表示）／常に表示／表示しない。ゲストはページ名と本文を検索できます。
- **ヘッダーを出さない**: 上部の「公開ページ」「ログイン」の帯を消します。
- **本文の上下の HTML**: お知らせや問い合わせ先などを、ゲスト画面の本文の上下に表示できます。ページごとは共有画面の「🧩 本文の上下に入れるHTML」、ワークスペース全体は「⋯ 操作」→「🌐 ゲスト向けの表示」。
- ページの [スタイル](/help/editing#ページの見た目スタイル) はゲストの画面にも効きます。

## PDF にする

共有画面の URL 欄の「PDF」、またはゲスト画面の「🖨 PDF」で、ゲストに見えている内容（公開版を固定していればその版）を目次付きの PDF にできます。

## 管理者向け

管理者は、画面右上の自分のアイコンのメニューの「公開中のページ」で、公開中のページの一覧（期間・パスワード・公開版の有無）を確認し、公開を止められます。
