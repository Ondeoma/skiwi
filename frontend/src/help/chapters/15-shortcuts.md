# キーボードショートカット

画面で <kbd>?</kbd> を押すと、いつでもこの一覧を出せます（入力中は除く）。Windows では <kbd>⌘</kbd> を <kbd>Ctrl</kbd>、<kbd>⌥</kbd> を <kbd>Alt</kbd> に読み替えてください。

## 全体

| キー | 操作 |
| --- | --- |
| <kbd>⌘</kbd> + <kbd>K</kbd> | クイック切り替え（ページ・ワークスペースへの移動、操作） |
| <kbd>⌘</kbd> + <kbd>\</kbd> | サイドメニューを開く・閉じる |
| <kbd>?</kbd> | ショートカットの一覧 |
| <kbd>Esc</kbd> | ダイアログ・メニューを閉じる／ページの選択を解除 |

## ページ

| キー | 操作 |
| --- | --- |
| <kbd>E</kbd> | 編集モードにする |
| <kbd>⌘</kbd> + <kbd>A</kbd> | 本文だけを全選択（エディタの外で。サイドメニューなどは選ばない） |
| <kbd>Esc</kbd> | 編集モードを終える（エディタの外で） |

## サイドメニュー

| 操作 | 結果 |
| --- | --- |
| <kbd>⌘</kbd> + クリック | ページを選択に加える・外す |
| <kbd>Shift</kbd> + クリック | 範囲をまとめて選ぶ |
| ダブルクリック | ページ名を変更 |
| 右クリック | ページのメニュー |
| ドラッグ | 並べ替え・移動 |

## エディタ

| キー | 操作 |
| --- | --- |
| <kbd>/</kbd> | ブロックを挿入 |
| <kbd>@</kbd> | メンション |
| <kbd>:</kbd> + 名前 | 絵文字 |
| <kbd>⌘</kbd> + <kbd>B</kbd> / <kbd>I</kbd> / <kbd>U</kbd> | 太字 / 斜体 / 下線 |
| <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | 取り消し線 |
| <kbd>⌘</kbd> + <kbd>E</kbd> | インラインコード |
| <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>H</kbd> | ハイライト |
| <kbd>⌘</kbd> + <kbd>⌥</kbd> + <kbd>1</kbd>〜<kbd>3</kbd> | 見出し1〜3 |
| <kbd>⌘</kbd> + <kbd>⌥</kbd> + <kbd>0</kbd> | 本文に戻す |
| <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>7</kbd> / <kbd>8</kbd> / <kbd>9</kbd> | 番号付きリスト / 箇条書き / ToDo |
| <kbd>⌘</kbd> + <kbd>Shift</kbd> + <kbd>B</kbd> | 引用 |
| <kbd>⌘</kbd> + <kbd>⌥</kbd> + <kbd>C</kbd> | コードブロック |
| <kbd>Tab</kbd> / <kbd>Shift</kbd> + <kbd>Tab</kbd> | リストの字下げ / 戻す |
| <kbd>Shift</kbd> + <kbd>Enter</kbd> | 段落を分けずに改行 |
| <kbd>⌘</kbd> + <kbd>A</kbd> | 本文全体を選択（コードブロックの中では、まずコードブロックの中身だけ。もう一度押すと本文全体） |
| <kbd>Shift</kbd> + <kbd>↑</kbd> / <kbd>↓</kbd> | 選択を広げる（段落の中は1行ずつ、段落の端からはブロック単位で） |
| <kbd>⌘</kbd> + <kbd>V</kbd> | 画像を貼り付け（スクリーンショットなど）。URL だけを貼るとカード・埋め込みを選べる |
| ⋮⋮ をドラッグ／クリック | ブロックの移動／ブロックのメニュー（変換・色・複製・リンク・移動・削除） |
