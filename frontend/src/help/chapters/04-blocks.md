# いろいろなブロック

編集モードで <kbd>/</kbd> を押して挿入します。ここではよく使うものの使い方を説明します。

## 表

`/表` で 3×3 の表を作ります。表の中にカーソルを置くと、左上に「表の操作」のつまみが出ます。

- 行・列の追加（上下・左右）と削除
- **セルの色**（選んだセルの背景色）
- **見出し行・見出し列**
- **結合／分割**: 複数のセルをドラッグで選んで「結合」。結合したセルで押すと分割。
- 表の削除

セルの境界をドラッグすると列の幅を変えられます。

## ToDo リスト・期限・担当者

`/ToDoリスト`（または行頭で `[ ]` + スペース）で、チェックボックス付きのリストを作ります。

- **担当者**: ToDo の行で `@` + 名前（または `/担当者`）。担当者の「✅ ToDo」（サイドメニュー）に表示されます。
- **期限**: `/期限` で日付を付けます。期限が近づく（今日・明日・過ぎた）と担当者に通知が届きます。日付をクリックで変更。

詳しくは [通知・ウォッチ・ToDo](/help/notify#todo) を見てください。

## 見出し・目次

見出し1〜3で文章を区切ると、`/目次` でページ内の目次を自動で作れます。表示する見出しの深さを選べ、クリックでその見出しへ移動します。

## 段組み

`/段組み（2列）` `/段組み（3列）` `/段組み（列数を指定）` で、内容を横に並べます（2〜12列）。

- 上の欄で **列数** と **幅の比**（例: 2:1、1:2:1、または数字で指定）を変えられます。列を減らしても中身は残ります。
- 画面が狭いと縦に並びます。
- 左上のつまみで段組みごと移動できます。

## 開閉ブロック

`/開閉ブロック` で、タイトルをクリックすると中身を開閉できるブロックを作ります。長い補足や FAQ に向いています。

**開閉見出し**: `/開閉見出し1`〜`/開閉見出し3` は、見出しの大きさのタイトルを持つ開閉ブロックです。章ごと畳んでおきたい長いページに向いています（目次にも出ます）。ブロックのつまみの「変換」で、ふつうの開閉ブロックとの間を行き来できます。

## パネル

注意書きや補足を目立たせる、アイコンと背景色付きの囲みです。`/情報パネル` `/注意パネル` `/成功パネル` `/エラーパネル` `/メモパネル`。
左のアイコンをクリックすると、アイコンと色を変えられます。「解除」で中身だけ残せます。

## 引用・コード

- `/引用`: 引用ブロック。
- `/コード`: 色分け付きのコード。右上で言語を選び、「コピー」ボタンで中身をコピーできます。

## 画像・ファイル・埋め込み

- `/画像`・`/ファイル`: アップロードして本文に入れます。画像の貼り付け（<kbd>⌘</kbd>/<kbd>Ctrl</kbd> + <kbd>V</kbd>）や、ファイルのドラッグ＆ドロップでも入れられます（[画像・ファイル](/help/editing#画像ファイル)）。
- `/埋め込み`: YouTube・Vimeo の動画、Figma・Google ドキュメント／スプレッドシート／スライド／ドライブ・Loom・Miro・CodePen・Spotify、そのほか https のページを本文の中に表示します（https 以外は埋め込めません）。共有用の URL をそのまま入れれば、埋め込み用の URL に自動で変えます。
- `/ブックマーク`: URL から、タイトル・説明・画像・アイコンのカードを作ります（GitHub などのページは OGP の情報を使います）。社内のアドレス（`192.168.…` など）は、管理者が許可していないと読み込みません。
- 画像には **キャプション**（画像の下の説明文）を付けられます。大きさは画像の四隅をドラッグして変えます。

## ページ内のデータベース

`/データベース（ページ内）` で、ページの本文の中にデータベースを表示します。

- 「＋ 新しいデータベースを作る」: このページの子ページとしてデータベースを作り、ここに表示します。
- 一覧から既存のデータベースを選ぶと、そのデータベースをこのページから見られます（リンクされたビュー）。
- 表示するビュー（絞り込み・並べ替え）は **このブロックごとに** 保存されます。元のデータベースのビューは変わりません。
- 値の入力・項目の追加もその場でできます（元のデータベースの権限に従います）。

使い方は [データベース](/help/database) と同じです。

## ページへのリンク

`/ページへのリンク` でページを検索して選びます。ページ名で表示され、名前を変えても自動で追従します。別のワークスペースのページにもリンクできます。

## 同期ブロック（同じ内容を複数のページに出す）

連絡先や共通の注意事項など、同じ内容を複数のページに載せたいときに使います。

1. 元のページで `/同期ブロックを作成` し、中に内容を書きます。
2. 載せたいページで `/同期ブロックを埋め込む` を選び、元のページ（と同期ブロック）を選びます。ページ全体を埋め込むこともできます。
3. 元を直すと、埋め込んだ先にも反映されます（埋め込んだ先では読み取り専用。「最新の内容を読み込む」で更新）。

元のページを閲覧できない人には、埋め込んだ部分は表示されません。

## ホワイトボード

`/ホワイトボード` で、付箋・図形・矢印・手書きなどを自由に描けるボードを作ります。ほかの人と同時に描けます。

- 右上のボタン: **全画面**（<kbd>Esc</kbd> で戻る）、**PNG画像として保存**、**コメント**、削除。
- 下端をドラッグすると高さを変えられます。
- 左上のタイトルのつまみをドラッグするとボードごと移動できます（ボードの中のドラッグは図形の操作になります）。
- 書き出し（ZIP）では Excalidraw のファイルとして保存されます。

## draw.io の図

`/draw.io 図` で、draw.io（diagrams.net）のエディタを開いて構成図・フロー図・画面遷移図などを描きます。Confluence で draw.io を使っていた人は、同じ操作で描けます。

- 描き終えたら、エディタの右上の **「保存して終了」** で本文に反映します。「閉じる（保存しない）」で取りやめます。
- 本文では画像として表示されます。編集モードで図に乗せて「✏️ 図を編集」（または図をダブルクリック）で、また編集できます。
- 図の中の文字（図形・矢印のラベル）も、ページの検索の対象になります。
- 保存した図は「図の名前.drawio.png」（図のデータを埋め込んだ PNG）として添付されます。この PNG はパソコンの draw.io でもそのまま開けます。
- パソコンの `.drawio.png`・`.drawio` のファイルを本文に貼り付け・ドロップしても、図のブロックになります。
- 同時に同じ図を編集すると、後から保存したほうが残ります（ページの本文は同時に編集できますが、1つの図の中は別々に保存されます）。

> 💡 エディタは diagrams.net のもの（ブラウザの中で動き、図は skiwi にだけ保存されます）を使います。社外のサイトにつなげない環境では、管理者が社内に draw.io を置いて設定します（[管理者向け](/help/admin#drawio-のエディタ)）。

## 図（Mermaid）・数式

- `/Mermaid図`: テキストからフローチャート・シーケンス図などを描きます。クリックで編集します。

  ```
  graph LR
    申請 --> 承認 --> 完了
  ```

- `/数式ブロック`・`/インライン数式`: LaTeX（KaTeX）で数式を書きます。文中で `$$x^2$$` のように `$$` で囲んでも入力できます。
